# Prompting como especificación

_Prompting as specification_ es la práctica de usar instrucciones, contexto, ejemplos, restricciones y criterios de salida para definir el comportamiento esperado de un modelo de lenguaje. En sistemas como GPT-3, el prompt dejó de ser solo una entrada textual y pasó a funcionar como una forma de especificar tareas: traducir, clasificar, resumir, responder, razonar paso a paso, adoptar un formato o seguir una pauta. Esta práctica se volvió más visible con modelos capaces de aprendizaje en contexto y con sistemas ajustados para seguir instrucciones.

Prompting conecta [[2020-gpt3-few-shot-learning]], [[rlhf-human-feedback]], [[base-model-product-layer]] y [[2022-chatgpt-product-layer]] con la dimensión operativa de los modelos conversacionales. En la genealogía de los modelos de lenguaje, el prompt actúa como una capa de control blanda: no modifica los pesos del modelo, pero orienta su comportamiento dentro de una interacción específica. Esta línea también se relaciona con [[verification-as-practice]], porque una buena especificación no solo pide una respuesta, sino que define condiciones, formato, fuentes, criterios de revisión y límites de uso.
