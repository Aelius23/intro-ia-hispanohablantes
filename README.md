# Introducción a la IA para hispanohablantes
## Genealogía de la IA · Genealogy of AI

Interactive bilingual knowledge graph and timeline tracing the history of artificial intelligence from Markov (1913) through ChatGPT (2022).

### Features
- **Interactive Force Graph** — D3.js force-directed network with 65 nodes and 108 connections
- **Timeline View** — Horizontal multi-track chronological timeline (WIP)
- **Bilingual** — Full Spanish/English toggle
- **Detail Panel** — Click any node to see descriptions and connections
- **Embeddable** — Designed for iframe embedding in HedgeDoc

### Embedding in HedgeDoc
```html
<iframe src="https://aelius23.github.io/intro-ia-hispanohablantes/grafo-interactivo.html" width="100%" height="700" frameborder="0" style="border-radius:12px;"></iframe>
```
